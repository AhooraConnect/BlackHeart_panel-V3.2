# Single-port panel (VLESS / Trojan over WebSocket)

یک پنل تک‌پورتی برای هاست‌های رایگان Node.js (Pterodactyl). بدون هیچ وابستگی npm.

## راه‌اندازی
1. یک سرور **Node.js** بساز (Node 18 یا بالاتر، ترجیحاً 20).
2. در **File Manager** این‌ها را آپلود کن: `index.js`، `package.json`، `package-lock.json` و پوشه‌ی `assets/`.
3. فایل استارت: `index.js` (دستور استارت: `node index.js`).
4. سرور را Start کن. پورت از `SERVER_PORT` خوانده می‌شود؛ لازم نیست تنظیمش کنی.
5. آدرس `http://<server-ip>:<port>/panel` را باز کن (برای وارد کردن رمز بهتر است `https://` را بزنی و هشدار گواهی خودامضا را تایید کنی) و رمز پنل را بساز.
6. لینک ساب یا کانفیگ‌ها را در کلاینت وارد کن.

پوشه‌ی `panel-data/` را نگه دار؛ رمز، UUID و گواهی TLS آنجاست. اگر پاک شود همه‌ی کانفیگ‌ها عوض می‌شوند.

## کانفیگ‌ها (همه روی همان یک پورت)
VLESS-WS، VLESS-WS-TLS، Trojan-WS، Trojan-WS-TLS. نسخه‌های TLS گواهی خودامضا دارند و لینک‌ها `allowInsecure=1` دارند.

## متغیرهای محیطی (اختیاری)
| متغیر | کاربرد |
| --- | --- |
| `UUID` | UUID ثابت |
| `PANEL_PASSWORD` | رمز ثابت پنل (حداقل ۸ کاراکتر) |
| `SUB_TOKEN` | توکن ثابت ساب |
| `SETUP_KEY` | کلید اضافه برای اولین ساخت رمز |
| `DOMAIN` | آدرس مورد استفاده در لینک‌ها |
| `PUBLIC_PORT` | پورت مورد استفاده در لینک‌ها (اگر با پورت داخلی فرق دارد) |

## مسیریابی در ساب‌ها
- **Bypass Iran**: دامنه‌های `.ir`، geosite و geoip ایران مستقیم می‌روند.
- **Bypass LAN**.
- **دامنه‌های همیشه-پروکسی** (پیش‌فرض: AI Studio، Gemini) قبل از Bypass Iran اجرا می‌شوند.

## هنوز انجام نشده
VMess، Shadowsocks، gRPC، XHTTP، اسکنر آی‌پی، QR داخل پنل، تست با کلاینت‌های واقعی.

## نسخه 0.2.0
- پورت‌های اضافه از پنل تیک می‌خورند و برای هر پروتکل فعال یک کانفیگ می‌سازند (فقط پورت‌هایی که هاست باز کرده).
- ساب جدا برای Xray Fragment (فقط کانفیگ‌های TLS).
- با هر تغییر، نسخه (rev) بالا می‌رود، ساب‌ها خودکار به‌روز می‌شوند و در پنل اعلان می‌آید. توکن قدیمی ساب ۳۰ روز کار می‌کند و پیام «لینک جدید را بگذار» می‌دهد.
- دامنه‌های گوگل به‌طور پیش‌فرض همیشه از پروکسی می‌روند و دکمه‌ی «بررسی کشور آی‌پی خروجی» اضافه شد.

## نسخه 0.3.0
- هر ساب حداقل ۱۰ کانفیگ دارد (قابل تنظیم). اگر (پروتکل × پورت) کمتر باشد، کانفیگ‌های اضافه با SNI، Host و fingerprint متفاوت ساخته می‌شوند.
- اسم کانفیگ‌ها مثل «👑 VLESS TLS · 443 · 2».
- لوگو در پنل، صفحه‌ی ورود، فاوآیکون و آیکون صفحه‌ی اصلی گوشی. فایل‌های `assets/*.png` را هم آپلود کن.
- گوگل: تمام دامنه‌ها و DNS گوگل از پروکسی می‌روند و اگر کلاینت آی‌پی بدهد، سرور با SNI دامنه‌ی واقعی را وصل می‌کند.
